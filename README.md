# CFD demo site, starter kit

Everything Claude Code needs is already here. You only paste the prompt.

## What is in this folder

| File | What it is |
|---|---|
| `PROMPT.md` | The prompt to paste into Claude Code. Start here. |
| `CLAUDE.md` | The rules Claude Code follows: design tokens, logo use, copy rules, scope. It reads this on its own. |
| `dir-floortime.html` | The approved page, already built. This is the design source for everything else. Do not let it get rewritten. |
| `brand/01-brand-facts.md` | Colour, type, logo, programs, pricing, team, insurance reality. |
| `brand/02-messaging-bank.md` | Approved headlines, support lines, CTAs, objection handling, banned words. |
| `brand/03-compliance-rules.md` | Meta policy, data handling, creative spec. |
| `assets/logo-color.png` | Colour lockup, transparent. For light backgrounds. |
| `assets/logo-white.png` | White knockout, transparent. For navy and dark backgrounds. |

## Steps

1. Open a terminal in this folder.
2. Run `claude`.
3. Paste the prompt from `PROMPT.md`.
4. When it finishes, run `npx serve .` and open the address it prints.
5. Click every link yourself before the meeting.

## Before the call

- Open all five pages in separate tabs ahead of time, so you switch tabs instead of waiting for loads.
- Browser at 100% zoom, full screen, no personal bookmarks or tabs visible.
- Take screenshots of every page and keep them in a PDF as a backup. If screen sharing fails, you still have something to show.

## What to say when you show it

> This is a demo, not the finished site. It runs on my machine. I built it so you can see the
> direction and react to it today. The real site gets the tracking, the forms and the booking
> connected, and it goes live on a new address before we touch your current one.

Her Wix site stays live. Nothing here touches it.

## Known gaps, on purpose

- Photos are placeholders. They get filled from the half-day shoot, with written consent per family.
- The 1:3 Harbor Academy ratio is left out until the client publishes it on their own site.
- Forms do not submit anywhere. The CRM webhook, the pixel and the Conversions API come with the real build.
- No Fairfield opening date, because there is not one yet.
